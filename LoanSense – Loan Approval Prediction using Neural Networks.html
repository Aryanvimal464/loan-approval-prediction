How it works

1. Data
Gender, income, loan amount, credit history, property area jaise 11 inputs.
2. Features
EMI, TotalIncome, Loan-to-Income aur log transforms automatic bante hain.
3. Preprocessing
Missing values fill, scaling, one-hot encoding.
4. Neural network
Do hidden layers (128, 64), ReLU, Adam, early stopping, GridSearchCV tuning.
5. Decision
Probability threshold se Approved ya Rejected.
